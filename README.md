# 직업가치관 밸런스 검사 · 중국어 어휘

어휘 듣기 → 발음 테스트(STT) → 사전 선택 → 밸런스 게임(36문항) → 결과 확인
서버·DB 없음, 어디에도 저장하지 않음.

## GitHub Pages 배포
1. 이 폴더 안의 파일을 저장소 맨 위(root)에 그대로 업로드
2. Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 접속

## 참고
- 발음 테스트는 Chrome(크롬북 포함)·Edge에서 동작, 마이크 권한 필요 (https 주소라 GitHub Pages에서 정상 작동)
- 중국어 글꼴: 朱雀仿宋을 `fonts/zhuque/`에 포함 (앱에 나오는 한자가 든 조각만, SIL OFL `LICENSE.txt` 동봉). 글자를 바꾸거나 추가하면 해당 조각이 빠졌을 수 있어요.
